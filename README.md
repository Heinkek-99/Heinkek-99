## Projets

### SchoolFlow · C# / .NET 8
API REST en architecture Clean et client desktop Windows pour la gestion d'une école : élèves,
familles, écolages, paiements et tableau de bord. CQRS avec MediatR, EF Core sur SQL Server,
authentification JWT, tests xUnit, intégration continue GitHub Actions.
[Code](https://github.com/Heinkek-99/SchoolFlow)

### Ecommerce · C# / .NET 8
Plateforme e-commerce : catalogue, panier, commandes, paiement par Stripe et programme de fidélité.
Monolithe modulaire en CQRS avec Wolverine, PostgreSQL, Redis, tests d'intégration.
[Code](https://github.com/Heinkek-99/Ecommerce)

### NexusMart · Python / FastAPI
Backend d'une marketplace en microservices : passerelle d'API, comptes, catalogue avec recherche

par service.
[Code](https://github.com/Heinkek-99/nexusmart-backend)

### Data-Telco · Python / FastAPI / React
Plateforme d'analyse client : tableaux de bord, analyse du churn, segmentation et export PDF.
[Démo en ligne](https://telco-analysis.vercel.app) · [Code](https://github.com/Heinkek-99/Data-Telco)

### Prudence · Java / Maven
Application de gestion scolaire en couches : persistance MySQL, journalisation Log4j2, tests JUnit 5
et Mockito.
[Code](https://github.com/Heinkek-99/prudence)
